# التنسيق والتكييف

> مرجع تفصيلي في شكل الصفحة وترويسة المشهد والوصف والحوار والانتقالات، ثم قواعد الاقتباس السينمائي. يُقرأ مع البابين ١٠–١١ من `SKILL.md`.

---

## ١. لماذا التنسيق

> «يعدّ التنسيق الشكلي للسيناريو عنصراً حاسماً بالنسبة إلى المنتج. إذ أن شكل الملف الذي يضم السيناريو هو ما يجعله يتخذ القرار بقراءة السيناريو أو بعدم قراءته» (هارو، ص ١١).

التنسيق ليس شكليات. هو **لغة مهنية** تجعل النص قابلاً للقراءة والتقدير والإنتاج.

---

## ٢. صفحة السيناريو

```text
مشهد ١٢ — داخلي — المطبخ — نهاراً

سعاد (٤٠) تقف أمام الثلاجة المفتوحة. تمسك
علبة حليب فارغة، تنظر إليها، ثم تضعها في
الرفّ نفسه.

تدخل ابنتها ليلى (١٦) حاملة حقيبتها.

ليلى
نسيتِ الحليب.

سعاد
(دون أن تستدير)
لم أنس.

قطع.
```

### ٢.١ العناصر

| العنصر | القاعدة |
| :--- | :--- |
| **رقم المشهد** | متسلسل |
| **داخلي/خارجي** | محدد |
| **المكان** | محدد |
| **الوقت** | نهاراً/مساءً/فجراً |
| **الوصف** | مضارع، جمل قصيرة |
| **اسم الشخصية** | ثابت |
| **التوجيه** | قليل |
| **الحوار** | منطوق |
| **الانتقال** | عند الحاجة |

### ٢.٢ الطول

> «صفحة من السيناريو تقابل دقيقة من الوقت على الشاشة» (فيلد، ص ١٩).

| النوع | الصفحات |
| :--- | :--- |
| فيلم روائي | ٩٠–١٢٠ |
| فيلم قصير | ٥–١٥ |
| حلقة | ٢٥–٤٥ |

---

## ٣. ترويسة المشهد

```text
مشهد ١٢ — داخلي — المطبخ — نهاراً
```

> «إذا حدثت نقلة زمنية دون أن يطرأ أي تغيير على الديكور، فإننا نغيّر رقم المشهد» (هارو، ص ٢٦).

**أخطاء:**
- ترويسة ناقصة.
- مكانان في مشهد واحد.
- وقت غير محدد.
- أرقام مكررة.

---

## ٤. الوصف

### ٤.١ القواعد

- المضارع.
- الجمل القصيرة.
- ما تراه الكاميرا.
- لا تفسير نفسي.
- لا تعليمات ممثلين إلا للضرورة.

### ٤.٢ قبل/بعد

| لا تكتب | اكتب |
| :--- | :--- |
| «يشعر بالحزن» | «يضع يده على كتفها، ثم يسحبها» |
| «لقطة قريبة على عينيه» | «عيناه. لا يرمشان» |
| «موسيقى حزينة» | اتركها للمخرج |
| «كانت الشمس تغيب» | «ضوء الغروب على الحائط» |
| «إنه غبي» | «يضع المفتاح في الثلاجة» |

**قاعدة:** الكاتب يكتب ما يُرى ويُسمع، لا ما يُفسَّر.

---

## ٥. الحوار

```text
اسم الشخصية
(توجيه أدائي، إن لزم)
النص المنطوق.
```

### ٥.١ قواعد

- اسم الشخصية في سطر مستقل.
- التوجيه بين قوسين وقليل.
- لا تكرر الأسماء في الحوار («كما قلت يا أحمد»).
- لا تشرح المشاعر في التوجيه.
- الحوار القصير أفضل.

### ٥.٢ تنسيق عربي

- استخدم علامات الترقيم العربية.
- لا تخلط الفصحى والعامية في السطر نفسه.
- ميّز اللهجات عند الحاجة.
- اكتب الأسماء بشكل ثابت.

---

## ٦. الانتقالات

| الانتقال | الاستخدام |
| :--- | :--- |
| **قطع** | الافتراضي |
| **اختفاء تدريجي** | نهاية مشهد/فصل |
| **ظهور تدريجي** | بداية |
| **قطع متطابق** | ربط بصري |

**قاعدة:** لا تكتب انتقالاً إلا إذا كان له معنى. «قطع» هو الأصل.

---

## ٧. التكييف

### ٧.١ قبل البدء

- **الحقوق:** من يملكها؟ هل العمل في الملك العام؟
- **الأمانة:** ما الذي ستحذفه؟
- **الشكل:** الرواية بالكلمات، والفيلم بالصور.

### ٧.٢ ما تحتفظ به

- السؤال المركزي.
- الرغبة والعائق.
- اللحظات البصرية.

### ٧.٣ ما تغيّره

| في الرواية | في الفيلم |
| :--- | :--- |
| سرد داخلي | فعل/صورة |
| شخصيات كثيرة | دمج |
| أزمنة متعددة | ضغط |
| وصف طويل | مشهد |
| فصول | مشاهد |

### ٧.٤ قاعدة الشكل

> «الاختلاف… لا يرجع إلى القصة ذاتها… فلا بد أن يكون الفارق إذن في الشكل» (أبو سيف، ص ٩).

لا تنقل فقرة حرفياً. اسأل: **كيف نرى هذا؟**

---

## ٨. الحقوق

| الحالة | الحكم |
| :--- | :--- |
| ملك عام | يجوز مع الإشارة |
| محمي/اقتباس | إذن الناشر/الورثة |
| محمي/إعادة تصور | إذن غالباً |
| قصة أشخاص أحياء | موافقة/تشويه سمعة |
| أغنية | حقوق موسيقية |
| لقطة من فيلم | حقوق المشهد |
| ترجمة | حقوق الترجمة |

**قاعدة:** لا تفترض أن «التغيير الكبير» يُعفي. استشر مختصاً قبل الإنتاج.
