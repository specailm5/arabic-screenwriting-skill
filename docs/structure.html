البنية

الثلاثية أداة، لا عقيدة.

الفكرة

الفكرة ليست موضوعاً. «الفقر» موضوع، و«أب يكذب على ابنه ليدخله مدرسة» فكرة.

اللوجلاين

«فكرة الفيلم… جملة بسيطة وقصيرة تلخص الفكرة القائدة للفيلم» (هارو، ص ١٢).

[شخصية] + [رغبة] + [عائق] + [رهان]

الملخص

«الملخص… يصف المفاصل الدرامية الكبرى… ويتراوح بين أربعة أسطر وصفحة ونصف الصفحة» (هارو، ص ١٥).

١. العالم والشخصية
٢. الحادث الذي يقلب الحالة
٣. الرغبة والعائق
٤. التصعيد
٥. الأزمة
٦. النهاية

المعالجة

«المعالجة… قد تبلغ عشرين صفحة أو أكثر… لا تتضمن أية حوارات، أو القليل منها» (هارو، ص ٢١).

وظيفتها: كشف مشاكل البنية قبل كتابة الحوار. ولا تقفز إلى السيناريو قبلها.
